Conexión a Neon PostgreSQL & Render

Estado del Backend: Comprobando...

La aplicación cuenta con servidor Node.js/Express listo para desplegar en Render y conectarse a tu base de datos Neon PostgreSQL.

¿Cómo vincular con tus otras aplicaciones en Neon?

  1. Misma Base de Datos o Esquema: Configura la variable de entorno DATABASE_URL en Render o en tu archivo .env.
  2. Tablas de Ventas de Café: La aplicación puede leer las tablas de café tostado por lotes y comercial para alimentar las ventas reales de cada mes.
  3. Tablas de P&G: El cruce "Real vs. Proyección" sincroniza costos operativos y gastos administrativos directamente.
  4. Persistencia Absoluta: Todas las estrategias, objetivos, actividades del cronograma y variaciones quedan respaldadas permanentemente en Neon.
